# The control plane's whole dependency list, pinned.
#
# Pinned to the version that was tested, because "Django>=5" is a request to
# be upgraded by whoever runs pip next. Hashes (--require-hashes) are the ops
# flow's job; exact versions are this one's.

# There is no JWT library here on purpose: minting an EdDSA token is one
# Ed25519 signature over two base64url segments (accounts/tokens.py), and the
# executor verifies it with Node's stdlib for the same reason. Neither side
# gains a package for the easy half of the problem.

django-cors-headers==4.9.0
# Sign-up, sign-in, verification by code, reset, the email and password
# changes, and later Google and MFA — through its headless JSON API.

# DATABASE_URL -> DATABASES, and the Postgres driver it names.

cryptography==50.0.1
